# Contributing

Thanks for helping bring India's knowledge heritage to children.

## Ways to help

- **Content:** suggest or review quests (Ayurveda, stories, astronomy). Domain accuracy matters; cite sources.
- **Code:** fix bugs, improve accessibility, add regional-language support.
- **Pilots:** share feedback from classroom or home use.

## Ground rules

1. **No real children's data** in issues, commits or sample files.
2. **Content must be age-appropriate** (ages 6–10) and avoid medical dosage or treatment claims.
3. **No biometric or emotion tracking** of children.
4. Keep pull requests small and describe what changed and why.

## Workflow

1. Fork the repository and create a branch: `git checkout -b feature/short-name`
2. Make your change and test it locally (see `README.md`).
3. Open a pull request with a clear description.
